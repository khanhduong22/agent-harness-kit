Checkout request flow

comic-storytelling style · four panels, read left to right, top to bottom · six components

  • client — browser, mobile, or device
  • service — application code we own
  • data — database, cache, object store
  • async — queue or worker (dashed arrow)
  • external — third party we do not run
  • error — failure path (long-short dash)
  • infra — platform and observability

Reading the story: panels are numbered and read left to right, then top to bottom, and they fade in one at a time in that order — the stagger IS the sequence. A speech bubble's tail points at the component doing the talking, the glowing node is the one acting in that beat, and the dashed arrow in panel four is the asynchronous publish. With reduced motion enabled all four panels are shown at once, fully drawn, so the whole story is on the page without waiting for anything.
